# NomadLogs · 簡易日記軟體

一個簡潔美觀、免安裝的網頁日記應用，純 HTML / CSS / JavaScript 打造，資料儲存在瀏覽器的 `localStorage`，開啟即可使用。

## 特色功能

- **密碼彩蛋 + 登出**：日記畫面預設就正常顯示；右上角有一個完全隱形的小熱區，點下去才會跳出密碼輸入框，輸入正確密碼會短暫顯示「✓」確認並恢復顯示（純前端字串比對，屬於小互動巧思，不是真正的存取控制）。側邊欄的「登出」只是把畫面收回成空白狀態的煙霧彈，不會動到任何日記資料，重新輸入密碼就能拿回一模一樣的內容
- **新增 / 編輯 / 刪除日記**：標題、內容、日期、地點（適合旅行紀錄）
- **心情標籤**：以 5 種表情符號快速標記當天心情（😊 開心／😌 平靜／😔 低落／🤩 興奮／😴 疲憊）
- **搜尋與篩選**：依關鍵字搜尋標題／內容／地點，或依心情篩選
- **深色模式**：一鍵切換淺色／深色主題，設定會被記住
- **匯出日記**：將所有日記匯出成純文字檔備份
- **側邊欄一鍵收合**：空間有限時，點側邊欄左上角的「«」按鈕，可以把 Logo、搜尋框、心情篩選、日記列表、底部按鈕列整組收起來，只留下「寫新日記」跟主要日記內容區，偏好設定會記住
- **響應式設計**：手機、平板、桌面皆可正常使用
- **無需後端**：所有資料保存在本機瀏覽器中，開啟 `index.html` 即可離線使用

## 使用方式

直接用瀏覽器開啟 `index.html`，或啟動一個本地伺服器：

```bash
python3 -m http.server 8000
```

接著造訪 `http://localhost:8000`。

## 專案結構

```
index.html   # 頁面結構
styles.css   # 樣式與主題（含深色模式）
app.js       # 應用邏輯（新增/編輯/刪除/搜尋/篩選/儲存）
```

## 資料儲存

所有日記資料儲存在瀏覽器的 `localStorage`（鍵值 `nomadlogs.entries`），僅存在於當前裝置與瀏覽器中，清除瀏覽器資料會一併清除日記，建議定期使用「匯出」功能備份。
